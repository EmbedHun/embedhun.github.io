1. 개요 및 배경

MCU는 최저 작동 전압(예: M2L31 은 1.71V)까지 동작할 수 있지만, 시스템에 탑재된 외부 장치(예: 최소 작동 전압이 2.7V인 외부 SPI Flash 메모리나 센서)는 그보다 높은 전압에서 먼저 동작 범위를 벗어납니다.

M2L31 데이터시트 — 8.2 General Operating Conditions 표의 VDD 동작 전압

이 전압 구간을 감지하는 하드웨어 주변장치가 브라운아웃 감지기(BOD, Brown-out Detector)입니다. BOD 는 AVDD 가 설정 전압(BODVL)을 지나 내려가거나 올라가는 것을 감지합니다.

이 가이드북은 누보톤 M2L31 시리즈를 기준으로 전압 강하 시 시스템 안정성을 지키는 BOD 설정법과 BOR(Brown-out Reset) 및 BOD 인터럽트 펌웨어 구현 예시를 제시합니다.

2. 브라운아웃 감지기(BOD)와 리셋(BOR)의 차이 및 역할

BOD 는 BODRSTEN 설정에 따라, 감지 전압이 임계값(BODVL)보다 낮을 때 리셋 또는 인터럽트를 발생시킵니다.

1) 브라운아웃 리셋 (BOR, Brown-out Reset)

BOD 리셋 기능(BODRSTEN=1)을 켜면, 감지 전압이 임계값보다 낮을 때(BODOUT=1) BOD 가 칩 리셋 신호를 냅니다.

2) 브라운아웃 인터럽트 (BOD Interrupt)

BOD 인터럽트 기능(BODRSTEN=0)을 켜면, BODOUT 이 1 일 때 BOD 인터럽트가 발생합니다. 다만 BOD 인터럽트 플래그(BODIF)는 전압이 임계값 아래로 내려갈 때뿐 아니라 임계값 위로 회복될 때도 세트되므로, ISR 에서 BODOUT 상태를 확인해 두 경우를 구분해야 합니다.

M2L31 TRM — SYS_BODCTL 레지스터의 BODIF·BODRSTEN 비트 설명(중간 생략)

3. 시스템 환경에 맞는 BOD 임계 전압 설정 기준

예시 시나리오:

  • MCU 최소 작동 전압: 1.71V (M2L31)
  • 외부 센서 및 SPI 플래시 메모리 최소 작동 전압: 2.7V
  • 시스템 권장 BOD 설정값: 2.8V (M2L31 BOD 선택지 중 2.7V 이상에서 가장 낮은 값)

M2L31 TRM — SYS_BODCTL 레지스터의 BODVL(BOD 임계 전압 선택) 필드(중간 생략)

설정 원리

BOD를 2.8V로 설정해 두면, 감지 전압이 2.8V보다 낮아질 때(BODOUT=1) 설정에 따라 리셋 신호 또는 인터럽트가 발생합니다.

4. BSP 기반 BOD/BOR 제어 펌웨어 구현법

누보톤 M2L31 시리즈의 시스템 매니저(SYS)의 BOD 제어 레지스터(SYS_BODCTL)를 BSP 드라이버 함수로 제어하여 BOD 기능을 2.8V 임계값으로 설정하고, 브라운아웃 인터럽트를 활성화하는 C 코드 예시입니다.

#include <stdio.h>
#include "NuMicro.h"
// BOD 인터럽트 서비스 루틴 (ISR)

void BOD_IRQHandler(void)
{
    // 1. BOD 인터럽트 플래그 확인
    if (SYS_GET_BOD_INT_FLAG())
    {
        // 2. 인터럽트 플래그 클리어
        SYS_CLEAR_BOD_INT_FLAG();
        // 3. 전압이 임계값 아래일 때만(회복 시에도 인터럽트가 걸리므로 BODOUT 로 구분) 최후의 비상 보호 조치 수행
        if (SYS_GET_BOD_OUTPUT())
        {
            // - 진행 중인 외부 플래시/EEPROM 쓰기 연산 즉각 중단
            // - I2C 및 SPI 핀들의 출력을 Safe State(High-Z 또는 Low)로 변경
            // - 구동용 모터 정지 명령 출력
            printf("BOD Warning: VDD voltage is dropping below 2.8V! Halting write tasks...\n");
        }
    }
}

void SYS_Init(void)
{
    // 시스템 레지스터 락 해제
    SYS_UnlockReg();
    // HIRC 내부 오실레이터 활성화 및 시스템 클럭 구성
    CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk);
    CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
    CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_CLKDIV0_HCLK(1));
    // 디버그 메시지용 UART 클럭 활성화
    CLK_EnableModuleClock(UART0_MODULE);
    CLK_SetModuleClock(UART0_MODULE, CLK_CLKSEL4_UART0SEL_HIRC, CLK_CLKDIV0_UART0(1));
    SYS->GPB_MFP3 = (SYS->GPB_MFP3 & ~(SYS_GPB_MFP3_PB12MFP_Msk | SYS_GPB_MFP3_PB13MFP_Msk)) |
    (SYS_GPB_MFP3_PB12MFP_UART0_RXD | SYS_GPB_MFP3_PB13MFP_UART0_TXD);
    // 시스템 레지스터 락 설정
    SYS_LockReg();
}

void BOD_Config_Setup(void)
{
    // 시스템 레지스터 보호 해제
    SYS_UnlockReg();
    // 1. BOD 기능 자체를 활성화 (BODEN 비트 세팅)
    // 2. BOD 감지 전압 레벨을 2.8V로 구성 (BODVL_2_8V 상수 대입)
    // 3. 임계치 이탈 시 강제 리셋(BOR) 대신 인터럽트 모드로 설정 (BODRSTEN 비트 해제)
    // 만약 전압 저하 시 즉각 강제 리셋을 걸고 싶다면 첫 번째 인자를 SYS_BODCTL_BOD_RST_EN으로 지정합니다.
    SYS_EnableBOD(SYS_BODCTL_BOD_INTERRUPT_EN, SYS_BODCTL_BODVL_2_8V);
    // 4. NVIC에서 브라운아웃 인터럽트 활성화 및 우선순위 최고 레벨로 지정
    NVIC_EnableIRQ(BOD_IRQn);
    NVIC_SetPriority(BOD_IRQn, 0);
    SYS_LockReg();
}

int main(void)
{
    SYS_Init();
    UART_Open(UART0, 115200);
    printf("BOD Monitoring System initialized.\n");
    // BOD 감지 시스템 기동
    BOD_Config_Setup();
    while(1)
    {
        // 전압 정상 상태에서의 일반 루프 작업 수행
        CLK_SysTickDelay(1000000);
    }
}

5. 임베디드 FAE 리스크 분석 및 예방 대책

BOD 출력 디글리치 설정

M2L31 의 BOD 에는 출력 디글리치 시간 선택(BODDGSEL) 기능이 있으며, SYS_BODCTL_BODDGSEL_xxHCLK 상수로 디글리치 시간(RC10K 샘플링 또는 3~4 HCLK 부터 255~256 HCLK 까지)을 설정할 수 있습니다.
