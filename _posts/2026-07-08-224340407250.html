전자공학도나 하드웨어 메이커에게 오실로스코프(Oscilloscope)는 회로의 신호를 눈으로 확인할 수 있게 해주는 가장 강력한 무기입니다. 하지만 수십만 원에서 수백만 원에 달하는 장비 가격 때문에 입문자들은 멀티미터에 만족해야 하는 경우가 많습니다.

이번 가이드에서는 단돈 3,000원의 부품비로 Nuvoton의 초저가 8비트 MCU인 N76E003과 0.96인치 OLED 디스플레이를 결합하여, 간단한 신호 파형을 실시간으로 측정하고 표시할 수 있는 자작(DIY) 미니 오실로스코프 제작 방법을 공유합니다.

---

▶ 1. N76E003 기반 미니 오실로스코프의 설계 구조

N76E003은 18KB Flash와 1KB SRAM을 가진 매우 제한적인 8051 계열 MCU이지만, 내부에 12비트 고속 ADC(Analog-to-Digital Converter)를 내장하고 있어 간단한 저주파 신호(최대 수십 kHz)의 파형을 검출하기에 충분합니다.

`mermaid

graph LR

subgraph Signal Input

A[Analog Signal Source] -->|Over-Voltage Protection & AC Coupling| B[ADC Channel 0: Pin 14]

end

subgraph Signal Processing (NuMicro N76E003)

B -->|12-bit Hardware ADC| C[Timer Triggered Sampling]

C -->|Waveform Buffer 256 bytes| D[OLED Rendering Driver]

end

subgraph Display Output

D -->|I2C Protocol: SCL/SDA| E[0.96 inch SSD1306 OLED]

end

`

1. 신호 입력단: 측정 대상 아날로그 신호를 MCU 입력 범위(0~3.3V)에 맞추기 위해 분압 및 다이오드 보호 회로를 거쳐 N76E003의 ADC 핀(AIN0)으로 입력합니다.

2. 타이머 트리거 샘플링: 안정적인 윈도우 뷰를 위해 타이머 인터럽트를 사용하여 일정한 주기로 ADC를 트리거하고 데이터를 256바이트 버퍼에 저장합니다.

3. 디스플레이 렌더링: I2C 통신을 통해 128x64 해상도의 OLED 디스플레이에 저장된 샘플 데이터를 점과 선으로 그려 실시간 파형을 복원합니다.

▶ 3. 하드웨어 회로 연결법

OLED 모듈과 N76E003 개발보드 간의 배선 연결 방법입니다.

📌

`text

[0.96인치 OLED (I2C)] [Nuvoton N76E003 개발판]

VCC (3.3V) <=========> 3.3V Out

GND <=========> GND

SCL <=========> P1.4 (I2C SCL)

SDA <=========> P1.3 (I2C SDA)

[신호 입력 프로브] [Nuvoton N76E003 개발판]

GND (검은선) <=========> GND

Signal (빨간선) <=======> P1.1 (AIN0 / ADC 채널 0)

`

⚠️

N76E003의 GPIO 입력 허용 전압은 최대 5.5V입니다. 이 이상의 전압이 인입되거나 음전압(AC 신호의 - 영역)이 들어오면 MCU가 영구적으로 파손될 수 있습니다. 따라서 입력단에 반드시 3.3V 제너 다이오드나 보호 클램핑 회로를 설계해 주어야 합니다.

▶ 4. 핵심 소스코드 구조 및 펌웨어

펌웨어는 Nuvoton Keil C51 BSP 라이브러리를 기반으로 작성됩니다. 핵심은 타이머 인터럽트를 이용한 주기적 ADC 획득과 OLED에 점(Pixel)을 그리는 드라이버 코드입니다.

▷ 1단계: 타이머를 활용한 정확한 ADC 트리거 설정

`c

void Init_Timer0(void)

{

TIMER0_MODE1_ENABLE; // 16비트 타이머 모드

TH0 = 0xFF; // 50kHz 샘플링 주기를 위한 타이머 카운터 설정

TL0 = 0x38;

set_ET0; // 타이머0 인터럽트 활성화

set_TR0; // 타이머0 시작

}

void Timer0_ISR(void) interrupt 1

{

// 타이머 값 재로드

TH0 = 0xFF;

TL0 = 0x38;

// ADC 소프트웨어 트리거 시작

set_ADCS;

while((ADCF == 0)); // ADC 변환 완료 대기

clr_ADCF; // 플래그 청소

// 버퍼에 12비트 상위 데이터를 8비트로 변환하여 저장

waveform_buffer[sample_index++] = ADCRH;

if(sample_index >= 128) {

sample_index = 0;

sampling_complete = 1; // 1프레임 획득 완료

}

}

`

▷ 2단계: OLED 화면에 버퍼 데이터 그리기

`c

void Draw_Waveform(void)

{

OLED_Clear(); // 화면 초기화

for(uint8_t x = 0; x < 128; x++)

{

// 8비트 ADC 값을 64픽셀 높이에 맞춰 스케일링

uint8_t y = 63 - (waveform_buffer[x] >> 2);

OLED_DrawPixel(x, y); // 각 픽셀 단위로 점 그리기

}

OLED_Refresh(); // OLED 화면에 물리적으로 버퍼 복사

}

`
