1. 개요 및 배경

누보톤 M55M1 시리즈(Cortex-M55)는 64KB ITCM(Instruction Tightly Coupled Memory)과 128KB DTCM 을 내장하며, ITCM 은 0x00000000 번지(Secure 주소)부터 배치됩니다. Cortex-M7 기반 KM1M7 시리즈도 ITCM 을 가집니다.

이 글은 누보톤 M55M1 에서 ITCM 영역에 코드를 할당하는 링커 파일 구성과 Keil 디버그 초기화 파일(.ini) 설정을 다룹니다.

2. 로드 주소와 실행 주소

컴파일 시 ITCM 함수는 플래시 메모리(M55M1 은 0x00100000 번지부터)에 로드(Load)용 바이너리로 저장되고, 실행 주소는 ITCM(0x00000000 번지부터)으로 배정됩니다.

그 결과 실행 시점에 CPU의 프로그램 카운터(PC) 레지스터는 ITCM 주소 대역(0x00000000~0x0000FFFF)의 주소를 가리키고 동작하게 됩니다.

3. 링커 분산 파일(Linker Scatter File / .ld) 포지셔닝 설계

Keil ARMCLANG 컴파일러 환경에서 함수(Delay_Loop)를 ITCM 영역으로 할당하기 위한 링커 파일(.sct) 구조입니다.

[Keil Scatter File (.sct) 구조]

LR_IROM1 0x00100000 0x00200000  // 플래시 로드 영역 정의 (M55M1: 0x00100000, 2MB)
{
    ER_IROM1 0x00100000 0x00200000
    {
        *.o (RESET, +First)
        *(InRoot$$Sections)
        .ANY (+RO)
    }
    // ITCM 실행 영역 매핑 정의
    // 로드 주소는 Flash 내에 존재하나 실행 주소는 ITCM 물리 영역(0x00000000 대역 등)으로 맵핑
    ER_ITCM 0x00000000 0x00010000
    {
        * (ITCM) // ITCM 영역 지정을 위한 섹션 명시
    }
    RW_IRAM1 0x20000000 0x00020000
    {
        .ANY (+RW +ZI)
    }
}

[C 소스코드 내 함수 섹션 속성 지정 선언]

__attribute__((section("ITCM"))) void Delay_Loop(uint32_t count)
{
    while(count--);
}

4. 디버그 초기화 스크립트 설정법 (.ini 파일 구성)

Keil MDK 에서는 Options for Target 의 Debug 탭에서 디버그 명령과 디버그 함수를 담은 초기화 파일(.ini)을 지정할 수 있습니다. Keil 어태치 모드 디버깅에서 디버그 심볼만 불러올 때는 LOAD %L INCREMENTAL 명령을 씁니다.

[Debug_Initialization.ini 파일 구성 내용]

// 1. 메모리 영역 접근 권한 지정 (MAP 명령은 µVision 시뮬레이터에서만 지원)
MAP 0x00000000, 0x0000FFFF READ WRITE EXEC     // ITCM 영역 읽기/쓰기/실행 권한 부여
MAP 0x20000000, 0x2001FFFF READ WRITE          // 일반 SRAM 영역
// 2. 디버그 심볼 로딩
LOAD %L INCREMENTAL // 디버그 정보를 기존 심볼 테이블에 추가로 로딩

설정 방법

  1. Keil 옵션 창(Options for Target)의 Debug 탭으로 진입합니다.
  2. Initialization File 항목에 위에서 만든 Debug_Initialization.ini 파일을 등록합니다.

5. 확인 사항

스타트업 복사 동작

링커 스크립터 파일(.sct)에 ITCM 영역을 지정한 경우, 런타임 시작 시 플래시(Load Region)의 원본 함수 바이너리를 ITCM(Execution Region)으로 복사하는 동작이 실행되어야 합니다. M55M1 BSP 의 Reset_Handler 는 마지막에 C 라이브러리 진입점(__PROGRAM_START, Keil 은 __main, GCC 는 __cmsis_start)을 호출하며, GCC 용 링커 스크립트는 ITCM 코드를 이 단계의 복사 표(copy table)에 'RO code for ITCM' 항목으로 등록해 둡니다.

인터럽트 벡터 테이블 위치

M55M1 BSP 에서 리셋 직후에는 플래시의 벡터 테이블(__VECTOR_TABLE)이 쓰이고, SystemInit() 에서 VTOR 이 DTCM 시작 주소(0x20000000)에 놓인 벡터 테이블(DTCM_VECTOR_TABLE)로 바뀝니다. NVT_VECTOR_ON_FLASH 를 정의하면 플래시의 벡터 테이블을 계속 씁니다.
