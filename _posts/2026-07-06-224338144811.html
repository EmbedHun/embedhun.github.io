1. 개요 및 배경

누보톤 N76E003 평가용 보드인 NuTiny-SDK-N76E003 보드는 N76E003AT20 이 실린 NuTiny-EVB-N76E003 과 디버그 어댑터인 Nu-Link-Me 로 이루어진 개발 보드입니다. Nu-Link-Me 는 PC 의 USB 포트에 연결되어 프로그래밍·디버깅을 지원하고, 온보드 N76E003AT20 의 UART0 에 연결되는 USB-UART 가상 COM 포트(Virtual COM Port) 기능도 지원합니다. VCOM Driver 를 설치하고 Nu-Link-Me 구역의 SW3 스위치를 모두 켜면 표준 COM 포트처럼 접근할 수 있습니다.

그러나 N76E003 UART 테스트 코드를 빌드하고 PC의 터미널 프로그램을 해당 포트로 열었는데도 수신 메시지가 나타나지 않고 송신 문자도 MCU로 들어가지 않는 경우가 있습니다.

이 가이드북은 NuTiny 보드의 VCOM 기능이 Nu-Link-Me 구역의 SW3 스위치로 켜고 끄는 방식이라는 점을 바탕으로, 스위치가 꺼져 있을 때 통신이 되지 않는 원인과 스위치 설정 방법을 설명합니다.

2. 오작동 원인 분석 (VCOM 스위치 OFF 상태)

확인할 하드웨어 원인은 Nu-Link-Me 구역의 VCOM 기능 스위치(SW3)가 OFF 로 되어 있는 경우입니다.

Nu-Link-Me 의 가상 COM 포트는 온보드 N76E003AT20 의 UART0(TXD_0: P0.6, RXD_0: P0.7)에 연결되며, 이 기능은 Nu-Link-Me 구역의 4극 스위치 SW3 로 켜고 끕니다. SW3 의 4개 스위치를 모두 OFF 로 두면 VCOM 기능이 비활성화되어 PC 터미널과 통신이 되지 않습니다.

따라서 VCOM 통신을 사용하려면 SW3 의 4개 스위치를 모두 ON 으로 설정해야 합니다.

3. 하드웨어 설정 단계 (SW3 스위치 ON)

NuTiny-SDK-N76E003 보드의 Nu-Link-Me 구역에는 가상 COM 포트 기능을 켜고 끄는 4극 스위치 SW3 가 있습니다.

복구 절차

  1. Nu-Link-Me 구역의 SW3 스위치를 찾습니다. SW3 는 4개의 스위치(1~4)로 이루어져 있습니다.
  2. SW3 의 1~4번 스위치를 모두 ON 위치로 올립니다. 모두 ON 이면 VCOM 이 활성화되고, 모두 OFF 이면 비활성화됩니다.
  3. 스위치가 ON 이 되면 Nu-Link-Me 의 가상 COM 포트가 N76E003 의 UART0(TXD: P0.6, RXD: P0.7)에 연결됩니다. 처음 사용하는 PC 라면 VCOM Driver 를 먼저 설치해야 하며, 드라이버는 NuMicroDVD 의 Software Utilities 폴더에서 받을 수 있습니다.

4. UART0 펌웨어 초기화 검증 소스코드

N76E003 보드에서 VCOM 연결을 확인하기 위해 38400bps 속도로 문자를 반복 송신하는 C 코드 예제입니다. 내장 16MHz HIRC 를 쓸 때는 보레이트 발생기의 한계 때문에 38400bps 이하 설정이 권장되므로 이 예제는 38400bps 로 구성했습니다.

#include "N76E003.h"

void UART0_Init_38400(void)
{
    // 1. P0.6(TXD)/P0.7(RXD) 핀 모드 설정: PxM1.n=0, PxM2.n=0 (준양방향)
    P0M1 &= ~0xC0;
    P0M2 &= ~0xC0;
    // 2. 타이머 1을 UART0의 보오레이트(Baud Rate) 발생기로 지정
    SCON = 0x50;     // UART0 모드 1 (8비트 데이터, 가변 속도), 수신 인에이블
    TMOD |= 0x20;    // 타이머 1 모드 2 (8비트 자동 재로드 타이머)
    // 3. 38400bps 보오레이트 설정 (내장 16MHz HIRC, SMOD=1, T1M=1: 보레이트 = FSYS/16/(256-TH1))
    PCON |= 0x80;    // SMOD=1 (UART0 배속)
    CKCON |= 0x10;   // T1M=1 (타이머 1 클럭 = FSYS)
    T3CON &= 0xDF;   // BRCK=0 (UART0 보레이트 클럭원 = 타이머 1)
    TH1 = 256 - (16000000UL / (16UL * 38400UL));
    TR1 = 1;         // 타이머 1 기동
    TI = 1;          // 첫 번째 전송 트리거용 송신 플래그 인에이블
}

void Send_Char_UART0(uint8_t c)
{
    while (!TI);    // 이전 버퍼 송신 완료 대기
    TI = 0;         // 송신 플래그 클리어
    SBUF = c;       // 직렬 포트 버퍼에 데이터 적재
}

void main(void)
{
    // UART 설정 (참고: WDT·BOD 같은 TA 보호 SFR 을 쓸 때는 TA=0xAA; TA=0x55; 를 먼저 써야 하며, UART 설정에는 필요 없음)
    UART0_Init_38400();
    while(1)
    {
        // PC 화면으로 'U' (0x55) 문자를 100ms마다 송신
        Send_Char_UART0('U');
        Timer3_Delay100ms(1);   // 100ms 지연 (Timer3 사용, 프로젝트 Define 에 FOSC_160000 필요)
    }
}
