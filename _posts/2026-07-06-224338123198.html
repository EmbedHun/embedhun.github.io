1. 개요 및 배경

USB 장치가 호스트(PC)와 올바르게 통신하려면 정확하고 왜곡 없는 송수신용 시리얼 클럭이 필수적입니다. USB 2.0 Full Speed(12Mbps) 통신 규격은 신호 타이밍 오차 범위를 최대 0.25% 이내로 엄격하게 규정하고 있습니다.

이 때문에 임베디드 개발자들은 통상적으로 회로 설계 시 외부 12MHz 오실레이터(크리스탈) 1개와 신호 매칭용 부하 커패시터 2개를 필수 배치하여 정밀 클럭을 공급해 왔습니다.

하지만 이러한 외부 소자들은 회로 기판(PCBA) 생산 과정에서 납땜 불량(냉납)으로 인한 오실레이터 발진 에러를 자주 유발하여 불량률을 높입니다. 또한 PCB 상의 실장 면적을 차지하고 부품 비용(BOM)을 상승시키는 단점이 있습니다.

누보톤은 이 문제를 완전히 극복하기 위해, 외부 크리스탈 없이 내장된 고정밀 48MHz RC 발진기(HIRC)와 실시간 동기 교정 하드웨어 엔진을 결합한 크리스탈리스 USB(Crystalless USB) 솔루션을 제공합니다.

이 가이드북은 누보톤 M031/M032 및 NUC126 시리즈를 바탕으로 외부 소자 없이 안정적인 USB 통신을 구현하는 하드웨어 제어 원리와 클럭 트리 펌웨어 설정법을 설명합니다.

2. 하드웨어 동작 원리 (SOF 실시간 주파수 자동 트리밍)

외부 크리스탈 없이 내장 RC 발진기(HIRC) 단독으로만 USB 통신을 시도하면, 온도 변화나 입력 전압의 요동에 따라 주파수가 드리프트되어 0.25%의 오차 범위를 넘어서며 통신 단절이 발생합니다.

누보톤은 이를 방지하기 위해 USB 호스트가 데이터 라인을 유지하기 위해 매 1ms 주기마다 전송하는 SOF(Start of Frame) 패킷 신호를 실시간 주파수 교정의 기준점으로 삼습니다.

실시간 자동 교정(Auto-Trim) 알고리즘 흐름

  1. USB 호스트가 매 1ms마다 타겟 보드에 SOF 패킷을 송신합니다.
  2. MCU 내부에 탑재된 USB 주파수 교정 하드웨어가 수신된 SOF 패킷의 주기를 카운팅합니다.
  3. 48MHz로 돌아가는 HIRC 클럭 소스와 비교하여 물리적인 주파수 오차를 계산합니다.
  4. 오차가 감지되면 하드웨어가 자동으로 HIRC 미세 조정 레지스터(HIRC Trim Register) 값을 조절하여 순간 오차를 0.25% 이내로 동기 수렴시킵니다.

이 과정을 하드웨어가 완전히 전담하여 수행하므로 CPU의 개입이나 소프트웨어 오버헤드 없이 전원 변동 및 실외 온도 변화(예: 영하 40도 ~ 영상 105도) 환경에서도 고신뢰성 USB 전송 속도를 보장합니다.

3. BSP 기반 크리스탈리스 USB 클럭 펌웨어 구현법

누보톤 M031/M032 시리즈에서 내장 48MHz HIRC를 동작시키고, USB 컨트롤러를 연결하여 자동 트리밍(Auto-Trim) 기능을 활성화하는 C 코드 가이드입니다.

#include <stdio.h>
#include "NuMicro.h"

void SYS_Init(void)
{
    // 시스템 레지스터 보호 해제
    SYS_UnlockReg();
    // 1. 내부 48MHz RC 발진기(HIRC) 활성화
    CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk);
    // 2. 클럭 소스가 안정화될 때까지 대기
    CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
    // 3. HCLK 클럭 소스를 HIRC(48MHz)로 선택하고 분주비를 1로 지정 (48MHz 동작)
    CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_CLKDIV0_HCLK(1));
    // 4. USB 모듈 클럭 인가 및 소스 지정
    CLK_EnableModuleClock(USBD_MODULE);
    // USB 클럭 분주비를 1로 지정하여 내부 USB 컨트롤러에 48MHz 인가
    CLK_SetModuleClock(USBD_MODULE, CLK_CLKSEL0_USBDSEL_HIRC, CLK_CLKDIV0_USB(1));
    // 시스템 레지스터 락 설정
    SYS_LockReg();
}

void USB_Trim_Configuration(void)
{
    // 시스템 레지스터 보호 해제
    SYS_UnlockReg();
    // 1. USB 하드웨어 자동 트리밍(Auto-Trim) 레지스터 활성화
    // - 첫 번째 인자: SYS_BASE (시스템 제어 블록)
    // - 두 번째 인자: 0 (트리밍 기준 소스로 USB SOF 신호 지정)
    // - 세 번째 인자: SYS_IRCTCTL_TENE_Msk (하드웨어 트리밍 엔진 인에이블)
    SYS_EnableUSBTrim(SYS_BASE, 0, SYS_IRCTCTL_TENE_Msk);
    // 2. 트리밍 하드웨어가 정상 동기화 락(Lock) 상태가 될 때까지 대기
    // SYS_IRCTISTS_32KERR_Msk 오류 상태나 락 완료 플래그를 체크합니다.
    while((SYS->IRCTCTL & SYS_IRCTCTL_TENE_Msk) && !(SYS->IRCTISTS & SYS_IRCTISTS_FREQLOCK_Msk))
    {
        // 락이 완료될 때까지 대기 루프 (정상 통신 진입 전 초기 안정화)
    }
    SYS_LockReg();
}

int main(void)
{
    SYS_Init();
    // USB 컨트롤러 장치 초기화 진행
    USBD_Open(&gsInfo, NULL, NULL);
    // 자동 주파수 튜닝 엔진 가동
    USB_Trim_Configuration();
    // USB 이벤트 인터럽트 활성화 및 서비스 기동
    USBD_Start();
    NVIC_EnableIRQ(USBD_IRQn);
    while(1)
    {
        // 일반 유저 루프 구동
    }
}

4. 임베디드 FAE 리스크 분석 및 예방 대책

EFT 과도 전압 노이즈 인입 시 주파수 오차 발생 리스크

크리스탈리스 USB 솔루션은 전압 변동에 정밀하게 대응하지만, 산업 현장에서 모터 가동 등으로 인한 높은 EFT(Electrical Fast Transient) 전기적 노이즈 서지가 VDD 라인에 직접 유입되는 경우, HIRC 내부 주파수가 순간적으로 크게 출렁거릴 수 있습니다. 이 출렁임이 수 밀리초(ms) 이상 지속되면 USB 연결이 순간 유실되는 에러가 납니다. 이를 대비하기 위해 타겟 MCU의 VDD 전원 입력 핀 바로 직전에 반드시 10uF 전해 커패시터와 0.1uF 세라믹 디커플링 커패시터를 병렬 배치하여 고주파 전원 노이즈를 완벽하게 감쇄시켜야 합니다.

USB 서스펜드(Suspend) 진입 시 클럭 제어 주의

USB 버스가 절전 모드(Suspend State)에 진입하면 호스트는 더 이상 매 1ms마다 보조 동기 신호인 SOF 패킷을 내보내지 않습니다. 따라서 서스펜드 모드 중에는 자동 트리밍 엔진이 중단됩니다. 펌웨어 작성 시, USB 서스펜드 인터럽트가 감지되는 즉시 자동 트리밍 제어 비트(TENE)를 일시적으로 해제(Disable)하고 내부 클럭 주파수를 저전력 모드로 강제 다운시켜 불필요한 전력 소모 및 주파수 폭주를 방지하십시오.
