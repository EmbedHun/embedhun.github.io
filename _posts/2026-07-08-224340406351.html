임베디드 개발자들에게 디버거(Debugger)는 떼려야 뗄 수 없는 필수 도구입니다. 하지만 매번 디버거 케이블이 꼬이거나, 타겟 보드와 PC 사이의 물리적 거리 때문에 불편을 겪은 적이 많으실 겁니다.

이번 가이드에서는 ESP8266(또는 ESP32) 칩 하나로 Keil MDK에서 무선으로 디버깅 및 다운로드가 가능한 자작(DIY) 무선 CMSIS-DAP 디버거 제작 방법을 공유합니다.

▶ 1. 무선 CMSIS-DAP 디버거의 동작 원리

이 자작 디버거의 핵심은 PC의 Keil MDK가 무선(Wi-Fi)을 통해 ESP 칩으로 데이터를 전송하고, ESP 칩이 USBIP와 CMSIS-DAP 프로토콜 스택으로 이를 처리해 타겟 MCU의 SWD(Serial Wire Debug) 핀을 직접 구동하는 구조입니다.

graph LR
subgraph Host PC
A[Keil MDK] --> B[USBIP / elaphureLink]
end
subgraph Wireless Debugger Node
B -->|Wi-Fi| C[ESP8266 / ESP32]
end
subgraph Target System
C -->|SWCLK / SWDIO / 3V3 / GND| F[Target MCU (ARM Cortex-M)]
end
  1. PC 호스트: USBIP(Windows는 usbip-win)로 ESP 칩에 연결합니다. Keil 사용자는 USBIP 없이 elaphureLink로 연결할 수도 있습니다.
  2. ESP 칩(ESP8266/ESP32): Wi-Fi로 받은 CMSIS-DAP 명령을 처리하여 자신의 GPIO로 타겟 MCU의 SWD(SWCLK, SWDIO) 신호를 만듭니다.

▶ 2. 준비물 (BOM List) 및 회로 레이아웃

📊

  • ESP8266 / ESP32 / ESP32C3 / ESP32S3 중 하나 (역할: Wi-Fi 연결, CMSIS-DAP 처리 및 SWD 신호 생성)
  • 3.3V LDO & 커패시터 (역할: ESP8266 전원 안정화용)
  • 만능기판 & 점퍼선 (역할: 하드웨어 뼈대 및 연결 라인)

▶ 3. 하드웨어 회로 구성 및 연결법

ESP8266과 타겟 MCU는 별도 회로 없이 선으로 직접 연결할 수 있습니다. SWD 신호선(SWCLK, SWDIO)과 전원선(3V3, GND)을 연결합니다.

📌

[ESP8266]                   [Target MCU]
3V3 (TVCC)   <=========>   Target 3V3
GND          <=========>   GND
GPIO14       <=========>   Target SWCLK
GPIO13       <=========>   Target SWDIO

⚠️

ESP8266의 동작 전류는 평균 80mA이고, 802.11b 송신 중에는 170mA(typical)입니다.

▶ 4. 펌웨어 빌드 및 업로드

이 프로젝트는 오픈소스로 공개된 CMSIS-DAP 펌웨어를 컴파일하여 업로드합니다.

▷ 1단계: ESP 칩에 wireless-esp8266-dap 펌웨어 빌드 및 업로드

ESP8266은 프로젝트에 포함된 ESP8266 RTOS SDK로, ESP32/ESP32C3는 esp-idf v4.4.2로 빌드한 뒤 idf.py로 업로드합니다. 빠른 평가용 샘플 펌웨어도 저장소의 Releases에 제공됩니다.

  • Wi-Fi 설정: 기본 접속 SSID는 DAP 또는 OTA, 비밀번호는 12345678이며 펌웨어 설정 파일(wifi_configuration.h)에서 바꿀 수 있습니다.

    ▶ 5. Keil MDK 디버거 설정법

    하드웨어가 준비되었으면 Keil MDK에서 무선 디버거를 설정합니다.

    1. USBIP 연결: PC에서 usbip-win으로 ESP 칩의 IP 주소에 연결합니다(예: usbip.exe attach_ude -r <ESP 칩 IP 주소> -b 1-1). Keil 사용자는 elaphureLink를 쓰면 USBIP 없이 연결할 수 있습니다.
    2. Keil 프로젝트 옵션 진입: Options for Target -> Debug 탭으로 이동합니다.
    3. 디버거 선택: Use: 드롭다운 목록에서 CMSIS-DAP Debugger를 선택하고 Settings를 클릭합니다.
    4. 연결 확인: 디버거가 연결되면 SW Device 항목에 Serial Wire로 연결된 타겟의 IDCODE와 Device Name이 자동으로 표시됩니다.
    5. 다운로드 및 디버깅: 이제 무선 상태에서 Ctrl+F5 키로 디버깅 세션을 시작합니다.
