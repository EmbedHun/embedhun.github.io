이번 가이드에서는 Nuvoton의 8비트 MCU인 N76E003과 0.96인치 OLED 디스플레이를 결합하여, 간단한 신호 파형을 실시간으로 측정하고 표시할 수 있는 자작(DIY) 미니 오실로스코프 제작 방법을 공유합니다.

▶ 1. N76E003 기반 미니 오실로스코프의 설계 구조

N76E003은 18KB Flash와 1KB SRAM(내부 RAM 256B + XRAM 768B)을 가진 8051 계열 MCU이며, 12비트 ADC(변환 속도 500ksps, 플래그 폴링 기준 샘플링 속도 380ksps)를 내장하고 있습니다.

N76E003 데이터시트 — ADC 전기적 특성표(Table 31-9)

subgraph Signal Input
A[Analog Signal Source] -->|Over-Voltage Protection & AC Coupling| B[ADC Channel 0: Pin 6]
end

C -->|Waveform Buffer 128 bytes| D[OLED Rendering Driver]

end
  1. 신호 입력단: 측정 대상 아날로그 신호를 MCU 입력 범위(0~3.3V)에 맞추기 위해 분압 및 다이오드 보호 회로를 거쳐 N76E003의 ADC 핀(AIN0)으로 입력합니다.
  2. 타이머 트리거 샘플링: 안정적인 윈도우 뷰를 위해 타이머 인터럽트를 사용하여 일정한 주기로 ADC를 트리거하고 데이터를 128바이트 버퍼에 저장합니다.
  3. 디스플레이 렌더링: I2C 통신을 통해 128x64 해상도의 OLED 디스플레이에 저장된 샘플 데이터를 점과 선으로 그려 실시간 파형을 복원합니다.

▶ 3. 하드웨어 회로 연결법

OLED 모듈과 N76E003 개발보드 간의 배선 연결 방법입니다.

📌

[0.96인치 OLED (I2C)]       [Nuvoton N76E003 개발판]
VCC (3.3V)   <=========>   3.3V Out
GND          <=========>   GND
SCL          <=========>   P1.3 (I2C SCL)
SDA          <=========>   P1.4 (I2C SDA)
[신호 입력 프로브]           [Nuvoton N76E003 개발판]
GND (검은선)  <=========>   GND
Signal (빨간선) <=======>   P1.7 (AIN0 / ADC 채널 0)

⚠️

N76E003의 VDD 외 핀에 걸 수 있는 전압의 절대 최대 정격은 -0.3V ~ VDD+0.3V입니다(VDD=3.3V이면 약 3.6V). 절대 최대 정격 이상의 전압은 소자에 영구 손상을 줄 수 있습니다.

▶ 4. 핵심 소스코드 구조 및 펌웨어

펌웨어는 Nuvoton Keil C51 BSP 라이브러리를 기반으로 작성됩니다. 핵심은 타이머 인터럽트를 이용한 주기적 ADC 획득과 OLED에 점(Pixel)을 그리는 드라이버 코드입니다.

▷ 1단계: 타이머를 활용한 ADC 트리거 설정

N76E003 데이터시트 — CKCON 레지스터의 T0M 비트 설명

N76E003 데이터시트 — 클럭 시스템 블록도(Figure 22.1-1)

void Init_Timer0(void)
{
    TIMER0_MODE1_ENABLE; // 16비트 타이머 모드
    TIMER0_FSYS;         // 타이머0 클록을 시스템 클록(Fsys 16MHz)으로 선택 (T0M=1)
    TH0 = 0xFE;          // 50kHz 샘플링 주기를 위한 타이머 카운터 설정 (320카운트 = 20us)
    TL0 = 0xC0;
    set_ET0;             // 타이머0 인터럽트 활성화
    set_TR0;             // 타이머0 시작
}

void Timer0_ISR(void) interrupt 1
{
    // 타이머 값 재로드
    TH0 = 0xFE;
    TL0 = 0xC0;
    // ADC 소프트웨어 트리거 시작
    set_ADCS;
    while((ADCF == 0));  // ADC 변환 완료 대기
    clr_ADCF;            // 플래그 청소
    // 버퍼에 12비트 상위 데이터를 8비트로 변환하여 저장
    waveform_buffer[sample_index++] = ADCRH;
    if(sample_index >= 128) {
        sample_index = 0;
        sampling_complete = 1; // 1프레임 획득 완료
    }
}

▷ 2단계: OLED 화면에 버퍼 데이터 그리기

void Draw_Waveform(void)
{
    OLED_Clear(); // 화면 초기화
    for(uint8_t x = 0; x < 128; x++)
    {
        // 8비트 ADC 값을 64픽셀 높이에 맞춰 스케일링
        uint8_t y = 63 - (waveform_buffer[x] >> 2);
        OLED_DrawPixel(x, y); // 각 픽셀 단위로 점 그리기
    }
    OLED_Refresh(); // OLED 화면에 물리적으로 버퍼 복사
}
