1. 개요 및 배경

누보톤은 SEGGER 로부터 emWin 라이브러리 라이선스를 받아, M480 BSP(V3.03.000 이후)에 NuMaker emWin 라이브러리와 예제 코드를 함께 제공합니다.

이 글은 누보톤 emWin 플랫폼을 기준으로, LCD 컨트롤러 인터페이스를 emWin 의 LCDConf.c 및 GUIConf.c 설정 파일과 연동하는 드라이버 포팅 예시를 다룹니다.

2. emWin 그래픽 엔진 구조 및 필수 구성 단계

emWin 라이브러리를 동작시키려면 하드웨어 디스플레이 드라이버 레이어와 emWin 그래픽 연산 코어 사이를 이어주는 중간 인터페이스 브리지 코드를 작성해 주어야 합니다.

핵심 설정 파일 구성

  • GUIConf.c: emWin이 사용할 내부 버퍼(GUI RAM Heap) 크기 및 동적 메모리 영역 지정
  • LCDConf.c: 디스플레이 해상도, 색상 깊이(Color Depth - RGB565 등), 디스플레이 드라이버 인터페이스 지정
  • GUI_X.c: 실시간 스케줄링 틱 동기화(RTOS 연동 시) 및 OS 인터페이스 처리

3. LCDConf.c 기반 저수준 드라이버 포팅 코드 가이드

누보톤 NuMaker-emWin-M487 보드에 탑재된 QVGA TFT LCD(드라이버 ILI9341, EBI 인터페이스로 연결)와 emWin 엔진의 프레임 버퍼 그리기 콜백을 동기화하는 핵심 이식 코드 구성입니다.

#include "GUI.h"
#include "LCDConf.h"
#include "NuMicro.h"
// 1. 디스플레이 해상도 규격 설정 (QVGA 320x240 예시)
#define XSIZE_PHYS 320
#define YSIZE_PHYS 240
// 2. 색상 물리 깊이 지정 (RGB565 16비트 포맷)
#define COLOR_CONVERSION GUICC_M565
#define DISPLAY_DRIVER   GUIDRV_TEMPLATE

void LCD_X_Config(void)
{
    // emWin 물리 디스플레이 엔진에 해상도 및 포맷 주입
    GUI_DEVICE_CreateAndLink(DISPLAY_DRIVER, COLOR_CONVERSION, 0, 0);
    // 화면 표시 영역 설정
    LCD_SetSizeEx(0, XSIZE_PHYS, YSIZE_PHYS);
    LCD_SetVSizeEx(0, XSIZE_PHYS, YSIZE_PHYS);
}
int LCD_X_DisplayDriver(unsigned int DeviceIndex, unsigned int Cmd, void * pData)
{
    int r = 0;
    switch (Cmd)
    {
        case LCD_X_INITCONTROLLER:
        // LCD 하드웨어 모듈 초기화 함수 호출
        break;
        case LCD_X_SETVRAMADDR:
        // VRAM 버퍼 주소 지정 필요 시 처리
        break;
        default:
        r = -1;
        break;
    }
    return r;
}

4. GUIConf.c 동적 메모리 공간 지정

emWin 이 사용할 메모리 블록과 그 크기를 지정합니다.

[GUIConf.c 힙 메모리 설정 코드]

#define GUI_NUMBYTES  0x8000 // emWin 전용으로 32KB SRAM 힙 영역 강제 할당

void GUI_X_Config(void)
{
    // 정적 전역 배열로 선언된 메모리 블록을 emWin 메모리 매니저에 등록
    static U32 aMemory[GUI_NUMBYTES / 4];
    GUI_ALLOC_AssignMemory(aMemory, GUI_NUMBYTES);
}

5. 확인 사항

메모리 할당(GUI_NUMBYTES) 크기 설정

emWin 의 메모리 요구량은 사용하는 모듈에 따라 달라지며, 윈도우 매니저와 위젯을 포함하는 시스템의 대략적인 기준은 RAM 20KB, 스택 1200바이트입니다. emWin 에 할당하는 메모리는 8·16·32비트 단위로 접근할 수 있어야 하며, NuMaker-emWin-M487 보드에는 1MB 외장 SRAM 이 탑재되어 있습니다.
