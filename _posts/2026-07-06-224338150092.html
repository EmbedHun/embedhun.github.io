1. 개요 및 배경

스마트 가전, 의료기기, 산업용 HMI 장치 설계 시 시각적으로 뛰어나고 반응이 빠른 사용자 인터페이스(GUI) 디자인 구현은 제품 경쟁력을 결정하는 중요한 요소입니다.

임베디드 하드웨어에서 GUI를 효율적으로 기동하기 위해 글로벌 반도체 업계에서 가장 안정성이 입증된 세거(Segger)사의 emWin 임베디드 그래픽 라이브러리를 표준으로 널리 활용합니다.

누보톤은 자사의 Cortex-M4(M487 등) 및 고성능 MCU 라인업을 위해 emWin 라이브러리 라이선스를 공식 매입하여, 자사 고객들이 로열티나 소프트웨어 구매 비용 없이 무료로 emWin GUI 솔루션을 개발 보드(NuMaker emWin 보드 등)에서 사용할 수 있도록 무상 지원하고 있습니다.

이 가이드북은 누보톤 emWin 플랫폼을 기준으로, LCD 컨트롤러 디바이스 인터페이스를 emWin 그래픽 엔진의 LCDConf.c 및 GUIConf.c 저수준(Low-level) 파일과 연동시키고 화면에 터치 버튼 및 컴포넌트를 기동시키는 표준 드라이버 포팅 프로시저를 상세히 제시합니다.

2. emWin 그래픽 엔진 구조 및 필수 구성 단계

emWin 라이브러리를 동작시키려면 하드웨어 디스플레이 드라이버 레이어와 emWin 그래픽 연산 코어 사이를 이어주는 중간 인터페이스 브리지 코드를 작성해 주어야 합니다.

핵심 설정 파일 구성

- GUIConf.c: emWin이 사용할 내부 버퍼(GUI RAM Heap) 크기 및 동적 메모리 영역 지정

- LCDConf.c: 디스플레이 해상도, 색상 깊이(Color Depth - RGB565 등), 디스플레이 드라이버 인터페이스 지정

- GUI_X.c: 실시간 스케줄링 틱 동기화(RTOS 연동 시) 및 OS 인터페이스 처리

3. LCDConf.c 기반 저수준 드라이버 포팅 코드 가이드

누보톤 M487 emWin 개발 보드에 탑재된 SPI/RGB LCD 드라이버 회로(ILI9341 등)와 emWin 엔진의 프레임 버퍼 그리기 콜백을 동기화하는 핵심 이식 코드 구성입니다.

4. GUIConf.c 동적 메모리 공간 지정

emWin 그래픽 창, 버튼, 폰트 렌더링에 사용될 전용 내부 힙 메모리 크기를 기입합니다.

[GUIConf.c 힙 메모리 설정 코드]

#define GUI_NUMBYTES 0x8000 // emWin 전용으로 32KB SRAM 힙 영역 강제 할당

void GUI_X_Config(void)

{

// 정적 전역 배열로 선언된 메모리 블록을 emWin 메모리 매니저에 등록

static U32 aMemory[GUI_NUMBYTES / 4];

GUI_ALLOC_AssignMemory(aMemory, GUI_NUMBYTES);

}

5. 임베디드 FAE 리스크 분석 및 예방 대책

메모리 할당(GUI_NUMBYTES) 부족에 따른 그래픽 비정상 다운 현상

emWin은 화면에 윈도우 창을 여러 개 띄우거나 회전, 알파 블렌딩(반투명), 대용량 비트맵 이미지를 그릴 때 메모리 힙(GUI_NUMBYTES)을 동적으로 마구 소비합니다. 만약 힙 크기를 너무 작게 주면, 런타임 도중 윈도우 생성 함수(WM_CreateWindow)를 호출하는 순간 아웃 오브 메모리(Out of Memory) 내부 어설션 경고와 함께 스크린 버퍼가 멈추고 시스템이 행(Hang) 상태가 됩니다. 복잡한 GUI 화면을 그릴 때는 힙 공간을 최소 32KB~64KB 이상으로 넉넉히 주거나, 칩셋 내부 SRAM 크기를 면밀히 계측하여 전용 외장 SDRAM 대역으로 GUI 힙 베이스 주소를 변경 지정하십시오.

터치스크린 센서 노이즈 및 좌표 보정 틀어짐 예외

저항막 방식 터치 디스플레이 사용 시 ADC 좌표 수집 타이밍에 임피던스 노이즈가 타고 들어오면 터치 위치가 심하게 떨리거나 오클릭 오작동이 유발됩니다. emWin의 GUI_TOUCH_StoreState API에 ADC 좌표값을 전달하기 전, 수집된 5~10개의 터치 좌표 샘플 데이터 중 최대값과 최소값을 제외하고 평균을 구하는 칼만 필터나 이동 평균 필터 알고리즘을 추가하여 정밀 좌표만 입력되도록 처리하십시오.
