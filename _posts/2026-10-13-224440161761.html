MA35D1 보드에 이미지를 쓰려고 NuWriter 를 열면 Attach 탭의 DDR File 항목이 가장 먼저 보입니다. 여기서 어떤 파일을 고르느냐에 따라 Attach 가 되기도 하고 안 되기도 합니다. 이 글은 DDR File 을 고르는 기준과 Custom DDR 모드 사용 순서를 NuWriter 화면과 함께 정리한 내용입니다.

참고: 이 글의 화면은 보드를 연결하지 않은 PC 에서 NuWriter GUI 를 직접 열어 캡처한 것입니다. 실제 보드 Attach 결과는 직접 찍지 못해서, 그 부분은 Nuvoton 매뉴얼과 Nuvoton 포럼 글을 출처로 밝혀 적었습니다. 이 글에서 "매뉴얼"이라고만 적은 것은 Nuvoton 의 MA35 Series NuWriter User Manual Rev 1.05 (파일 이름 UM_EN_MA35_NuWriter.pdf) 입니다.

1. Attach 에 DDR 초기화 파일이 필요한 이유

Attach 는 NuWriter 가 MA35 와 통신하기 위한 연결을 만드는 명령입니다. 저장 장치에 접근하려면 이 연결이 먼저 있어야 하고, convert 와 pack 을 뺀 다른 명령은 연결을 만든 뒤에만 실행할 수 있습니다. NuWriter 매뉴얼(UM_EN_MA35_NuWriter)은 Attach 에 쓰는 DDR initialize code 가 사용자의 하드웨어 설정과 일치해야 한다고 설명합니다. 보드에 실장된 DDR 종류와 용량이 다르면 맞는 파일도 달라집니다. Nuvoton 은 지원하는 파일을 NuWriter 의 ddrimg 폴더에 모아 두었습니다.

NuWriter 를 처음 열었을 때의 Attach 탭. DDR File 기본값으로 MA35D03F864C.bin 이 들어 있습니다.

2. ddrimg 폴더에서 파일 고르기

DDR File 의 Browse 를 누르면 ddrimg 폴더의 .bin 목록이 나옵니다. 제가 받은 NuWriter 폴더에서 확인한 파일 일부입니다.

  • enc_ddr2_winbond_128mb.bin
  • enc_ddr3_issi_1gb.bin
  • enc_ddr3_micron_1gb.bin
  • enc_ddr3_winbond_256mb.bin
  • enc_ddr3_winbond_512mb.bin
  • enc_ddr3_zentel_1gb.bin
  • MA35D03F764C.bin, MA35D03F864C.bin
  • MA35D15A087C_NonMCP_WBDDR3L_1GB.bin, MA35D15A087C_NonMCP_WBDDR3L_1GBx2.bin

Browse 로 연 ddrimg 폴더의 파일 목록

어느 파일이 어느 칩에 해당하는지는 같은 폴더의 readme.txt 에 정리되어 있습니다. 예를 들면 다음과 같습니다.

  • MA35D16F787C.bin : LQFP216, DDR2 Winbond 128MB
  • MA35D16A087C_NonMCP_WBDDR3L_1GBx2.bin : LFBGA-364 NonMCP, DDR3 Winbond 1GB(W638GU6QB11I) 2개

매뉴얼 기준으로 정리한 선택 기준입니다.

  • NuMaker-HMI-MA35D1 보드: enc_ddr3_winbond_256mb.bin 선택 (매뉴얼 7.1절)
  • MCP 패키지: Winbond DDR3 256MB, Winbond DDR3 512MB, Winbond DDR2 128MB 지원 (매뉴얼 6.2절)
  • 외부 DDR 구성: Micron DDR3 1GB, ISSI DDR3 1GB, Zentel DDR3 1GB 지원 (매뉴얼 6.2절)

파일을 선택하면 DDR File 칸에 경로가 들어갑니다. 아래는 enc_ddr3_winbond_256mb.bin 을 고른 상태입니다.

3. Attach 실행

DDR File 을 고른 뒤 Attach 를 누르면 GUI 가 내부적으로 CLI 의 attach 명령을 실행합니다. CLI 로 직접 쓰면 형식은 다음과 같습니다.

nuwriter.py -a MA35D16F787C.bin

매뉴얼 3.2절에 따르면 NuWriter 는 Power-On-Setting PG[7:4] 로 저장 매체의 속성을 판단합니다. 예를 들어 PG[7:6] 은 접근할 SD 인터페이스를 고르고 NAND 플래시에 접근할 때의 ECC 도 정합니다. 그래서 PG[7:4] 는 접근할 저장 매체에 맞게 설정해야 하고, SD1 에 쓰려면 보드의 NAND 플래시 ECC 설정과 상관없이 PG[7:6] 을 01 로 설정합니다. 매뉴얼 Table 3-1 의 값은 다음과 같습니다. PG[5:4] 는 NAND 플래시 페이지 크기로 00 은 Ignore, 01 은 2 KB, 10 은 4 KB, 11 은 8 KB 입니다. PG[7:6] 은 부팅 매체에 따라 뜻이 달라집니다. SD/eMMC 부팅이면 00 은 SD0/eMMC0 4-bit, 01 은 SD1/eMMC1 4-bit, 10 은 eMMC0 8-bit, 11 은 eMMC1 8-bit 입니다. NAND 부팅이면 00 은 Ignore, 01 은 BCH T12, 10 은 BCH T24, 11 은 No ECC 입니다. SPI 플래시 부팅이면 00 은 SPI-NAND 1-bit, 10 은 SPI-NOR 1-bit 이고 나머지는 reserved 입니다. NuMaker-BASE-MA35D1 V2.0 보드 회로도에서는 PG0~PG7 이 8칸 DIP 스위치 SW4 의 1~8번에 차례로 연결되어 있어, PG[7:4] 는 5~8번 칸입니다. 매뉴얼 Figure 3-1 의 보드 사진에는 이 스위치에 ON (High), OFF (Low) 라고 표기되어 있습니다. 회로도에는 PG0~PG7 핀이 칩 내부에서 pull-low 되어 있다고 적혀 있습니다. 실제 보드에서 스위치를 조작해 확인한 내용은 아닙니다. 매뉴얼 6.2절은 NuWriter 가 올바른 SD/eMMC 인터페이스를 제어하려면 Attach 명령을 실행하기 전에 power on setting 을 알맞게 설정해야 한다고 설명합니다. 또 Attach 전에 info.json 으로 장치의 플랫폼 정보를 지정할 수 있습니다. 화면에서 Use Info.json as set info 를 체크하고 Info.json 의 Browse 로 기존 파일을 고른 뒤 Set Info.json 을 누르면 내용을 보고 설정할 수 있고, Export 로 새 info.json 을 저장할 수 있습니다. CLI 에서는 setinfo 옵션을 주면 NuWriter 가 info.json 파일에서 속성을 읽습니다. 매뉴얼은 속성 감지 오류 때문에 NuWriter 가 프로그램하지 못하는 저장 장치에 setinfo 옵션으로 속성을 지정할 수 있다고 설명합니다.

Attach 를 하려면 보드와 PC 를 연결해야 합니다. MA35 의 IBR 은 USB 포트 0 으로 NuWriter 와 통신하므로 USB 케이블로 보드와 PC 를 연결합니다. PC 와 MA35 의 UART0 를 잇는 UART 케이블은 NuWriter 펌웨어가 출력하는 디버그 메시지를 보는 용도이고, PC 와 MA35 사이의 데이터 전송에는 쓰이지 않습니다. NuMaker-HMI-MA35D1 보드의 USB 와 UART 위치는 매뉴얼 3.1절 그림에 나와 있습니다. 보드를 연결하지 않고 Attach 를 누르면 아래처럼 Device not found 가 표시됩니다.

보드가 연결되지 않은 상태에서 Attach 를 누른 결과

4. Attach 오류 사례 - No backend available

Nuvoton 포럼(Q&A 14636, 2025-09-30)에 MA35D16AJ87C 보드에서 Attach 시 아래 오류가 나온 사례가 올라와 있습니다.

SystemExit: No backend available ... AttributeError: 'XUsbComList' object has no attribute 'devices'

해당 글의 해결 방법은 다음과 같습니다.

  • SourceForge 에서 libusb-1.0.29.7z 를 받는다
  • 압축 안의 MinGW64 폴더에 있는 libusb-1.0.dll 을 C:\Windows\System32 로 복사한다
  • MA35D16AJ87C.bin 으로 Attach 를 다시 실행한다

같은 글에서 정상 Attach 시 출력이 Successfully attached 1 device(s) 로 시작한다고 나옵니다.

5. 외부 2GB DDR 보드

Nuvoton 포럼 Q&A 11231(2024-04-11)은 외부 2G DDR EVB 사용법을 다룹니다. 요점만 옮깁니다.

  • NuWriter DDR 파일: MA35D1_NuWriter/ddrimg/MA35D16A087C_NonMCP_WBDDR3L_1GBx2.bin
  • Buildroot: MA35D1_Buildroot/board/nuvoton/ma35d1/uboot-env.txt 의 kernelmem 을 2048M 으로 설정
  • Buildroot defconfig: numaker_som_ma35d16ab1a_defconfig

6. Custom DDR 모드

ddrimg 에 맞는 파일이 없는 DDR 을 쓸 때는 Custom DDR 모드를 사용합니다. Nuvoton 이 제공하는 Excel 파일 ddrmctl2_phy_auto_init_settings_v3.01.xlsm 에 DDR 파라미터를 입력하면 ddr_init.txt(NuWriter 용)와 ddr_init_param.h(TFA 용)가 생성됩니다. 이후 순서는 매뉴얼 8장 기준으로 다음과 같습니다.

  • Mode -> Custom DDR mode 선택
  • Browse 로 ddr_init.txt 선택
  • Convert 를 누르면 ddr.bin 이 생성됨
  • Attach 실행

Custom DDR mode 화면. DDR File, Browse, Convert 와 DDR Speed 선택이 있습니다.

제가 받은 버전의 화면에는 DDR Speed 항목(1066, 800, 667 mbps)이 있습니다. 이 항목은 매뉴얼 8장에 설명이 없어서 용도는 확인하지 못했습니다.

정리

  • Attach 의 DDR File 은 보드에 실장된 DDR 과 맞아야 합니다. 파일 목록은 ddrimg\readme.txt 로 확인합니다.
  • NuMaker-HMI-MA35D1 은 enc_ddr3_winbond_256mb.bin 입니다.
  • Attach 오류 중 No backend available 은 libusb-1.0.dll 을 System32 에 넣어 해결한 사례가 있습니다.
  • 목록에 없는 DDR 은 Custom DDR 모드로 ddr.bin 을 만들어 사용합니다.
