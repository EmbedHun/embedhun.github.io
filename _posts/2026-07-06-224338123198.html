1. 개요 및 배경

USB 2.0 Full Speed(12Mbps) 장치에는 USB 프로토콜이 요구하는 정밀한 주파수의 클럭이 필요합니다.

외부 크리스탈을 쓸 경우, 발진 회로는 크리스탈 1개와 부하 커패시터 2개(C1, C2)로 구성됩니다.

이러한 외부 소자는 PCB 실장 면적과 부품 비용(BOM)을 늘립니다.

누보톤은 외부 크리스탈 없이 내장 48MHz RC 발진기(HIRC)와 자동 트림(Auto-Trim) 기능을 이용하는 크리스탈리스 USB(Crystal-less USB) 기능을 제공합니다.

이 가이드북은 누보톤 M031/M032 시리즈(USB 장치 기능은 M032 에만 있음)를 바탕으로 외부 크리스탈 없이 USB 통신을 구현하는 하드웨어 제어 원리와 클럭 트리 펌웨어 설정법을 설명합니다.

2. 하드웨어 동작 원리 (SOF 실시간 주파수 자동 트리밍)

내장 48MHz RC 발진기(HIRC)는 생산 단계에서 교정되며, 주파수 편차는 25°C·VDD 3.3V 에서 -1~1%, -40~105°C·VDD 1.8~3.6V 에서 -2~2% 입니다.

누보톤은 이 편차를 줄이기 위해 USB 호스트가 매 1ms 주기마다 전송하는 SOF(Start of Frame) 패킷 신호를 주파수 교정의 기준으로 삼습니다.

실시간 자동 교정(Auto-Trim) 알고리즘 흐름

  1. USB 호스트가 매 1ms마다 타겟 보드에 SOF 패킷을 송신합니다.
  2. MCU 내부의 자동 트림 회로는 USB 동기 모드(REFCKSEL=1)에서 기준 클럭과 HIRC 의 주파수 차이를 계산합니다.
  3. 계산은 기준 클럭 4·8·16·32 클럭 동안의 평균 주파수 차이를 바탕으로 하며, 몇 클럭을 쓸지는 LOOPSEL 필드로 고릅니다.
  4. 자동 트림 회로는 이 계산을 바탕으로 HIRC 트림 값을 갱신하고, HIRC 주파수가 48MHz 에 잠기면 FREQLOCK(SYS_HIRCTRIMSTS[0]) 이 1 이 됩니다. FREQLOCK 이 1 이면 HIRC 출력 주파수가 0.25% 편차 이내라는 뜻입니다.

자동 트림이 동작하면 HIRC 출력 주파수는 전 온도 범위에서 0.25% 편차 이내로 맞춰집니다. 다만 트림을 시작하고, 오류(CLKERIF·TFAILIF)가 나면 트림을 끄는 일은 아래 코드처럼 소프트웨어가 맡습니다. 트림 값 갱신 횟수가 RETRYCNT 로 정한 한도(64·128·256·512회)에 이르도록 주파수가 잠기지 않으면 자동 트림이 꺼지고 FREQSEL 이 00 으로 지워집니다.

3. BSP 기반 크리스탈리스 USB 클럭 펌웨어 구현법

누보톤 M031/M032 시리즈에서 내장 48MHz HIRC를 동작시키고, USB 컨트롤러를 연결하여 자동 트리밍(Auto-Trim) 기능을 활성화하는 C 코드 가이드입니다.

#include <stdio.h>
#include "NuMicro.h"

void SYS_Init(void)
{
    // 시스템 레지스터 보호 해제
    SYS_UnlockReg();
    // 1. 내부 48MHz RC 발진기(HIRC) 활성화
    CLK_EnableXtalRC(CLK_PWRCTL_HIRCEN_Msk);
    // 2. 클럭 소스가 안정화될 때까지 대기
    CLK_WaitClockReady(CLK_STATUS_HIRCSTB_Msk);
    // 3. HCLK 클럭 소스를 HIRC(48MHz)로 선택하고 분주비를 1로 지정 (48MHz 동작)
    CLK_SetHCLK(CLK_CLKSEL0_HCLKSEL_HIRC, CLK_CLKDIV0_HCLK(1));
    // 4. USB 모듈 클럭 인가 및 소스 지정
    CLK_EnableModuleClock(USBD_MODULE);
    // USB 클럭 분주비를 1로 지정하여 내부 USB 컨트롤러에 48MHz 인가
    CLK_SetModuleClock(USBD_MODULE, CLK_CLKSEL0_USBDSEL_HIRC, CLK_CLKDIV0_USB(1));
    // 시스템 레지스터 락 설정
    SYS_LockReg();
}
// 자동 트림 오류 시 복귀할 기본 트림 값의 주소와 보관 변수
#define TRIM_INIT (SYS_BASE+0x118)
uint32_t g_u32TrimInit;

void USB_Trim_Configuration(void)
{
    // 시스템 레지스터 보호 해제
    SYS_UnlockReg();
    // 1. 자동 트림이 꺼져 있고 USB SOF 가 들어온 경우에만 자동 트림을 시작합니다.
    if(((SYS->HIRCTRIMCTL & SYS_HIRCTRIMCTL_FREQSEL_Msk) != 1) && (USBD->INTSTS & USBD_INTSTS_SOFIF_Msk))
    {
        // SOF 플래그를 지우고 자동 트림 시작 (FREQSEL=01, 기준 클럭은 USB SOF)
        USBD->INTSTS = USBD_INTSTS_SOFIF_Msk;
        SYS->HIRCTRIMCTL = 0x01;
        SYS->HIRCTRIMCTL |= SYS_HIRCTRIMCTL_REFCKSEL_Msk;
    }
    // 2. 클럭 오류(CLKERIF) 또는 트림 실패(TFAILIF)가 발생하면 트림을 끄고 기본 트림 값으로 복귀합니다.
    if(SYS->HIRCTRIMSTS & (SYS_HIRCTRIMSTS_CLKERIF_Msk | SYS_HIRCTRIMSTS_TFAILIF_Msk))
    {
        M32(TRIM_INIT) = g_u32TrimInit;
        SYS->HIRCTRIMCTL = 0;
        SYS->HIRCTRIMSTS = SYS_HIRCTRIMSTS_CLKERIF_Msk | SYS_HIRCTRIMSTS_TFAILIF_Msk;
        USBD->INTSTS = USBD_INTSTS_SOFIF_Msk;
    }
    SYS_LockReg();
}

int main(void)
{
    SYS_Init();
    // USB 컨트롤러 장치 초기화 진행 (USBD_HID_Mouse 샘플과 같은 호출 형태이며, gsInfo 와 클래스 요청 콜백은 사용하는 USB 클래스 코드에 맞춰 지정)
    USBD_Open(&gsInfo, HID_ClassRequest, NULL);
    // USB 이벤트 인터럽트 활성화 및 서비스 기동
    USBD_Start();
    NVIC_EnableIRQ(USBD_IRQn);
    // 기본 트림 값 백업 후 SOF 플래그 클리어
    g_u32TrimInit = M32(TRIM_INIT);
    USBD->INTSTS = USBD_INTSTS_SOFIF_Msk;
    while(1)
    {
        // SOF 가 들어오면 자동 트림 시작, 오류 시 트림 해제 (메인 루프에서 반복 호출)
        USB_Trim_Configuration();
        // 일반 유저 루프 구동
    }
}

4. 임베디드 FAE 리스크 분석 및 예방 대책

USB 서스펜드(Suspend) 진입 시 클럭 제어 주의

USB 버스가 절전 모드(Suspend State)에 진입하면 호스트는 더 이상 매 1ms마다 SOF 패킷을 내보내지 않습니다. M031 BSP 의 CLK_PowerDown() 은 HIRCTRIMCTL 의 FREQSEL 이 켜져 있으면(자동 트림 동작 중이면) 파워다운에 들어가지 않고 바로 반환하므로, 서스펜드 처리 시에는 자동 트림을 먼저 끈(HIRCTRIMCTL 의 FREQSEL 을 0 으로 만든) 뒤 파워다운에 진입하십시오. 깨어난 뒤에는 SOF 가 다시 들어오면 트림을 다시 켜면 되며, 위 코드의 메인 루프가 그 역할을 합니다.
