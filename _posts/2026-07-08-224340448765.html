인공지능(AI)과 딥러닝 기술이 고도화됨에 따라 고가의 GPU 서버 없이도 말단 기기(Edge)에서 스스로 연산을 수행하는 온디바이스(On-device) AI / Edge AI가 임베디드 업계의 최대 화두가 되었습니다. 특히 스마트 홈, 스마트 가전 등에서 손동작만으로 전원을 끄고 켜거나 조명을 조절하는 비접촉식 제스처 인식 시스템에 대한 수요가 높아지고 있습니다.

이번 가이드에서는 ARM Cortex-M55 코어와 Ethos-U55 NPU(신경망 처리 장치)를 내장한 Nuvoton의 고성능 ML MCU인 NuMicro M55M1을 사용하여, 저가형 CMOS 카메라로 손동작을 실시간(Real-time)으로 추적하고 분류하는 Edge AI 제스처 인식 카메라 구현 방법을 상세히 공유합니다.

---

▶ 1. M55M1 ML 시스템의 동작 아키텍처

NuMicro M55M1은 머신러닝 연산에 최적화된 하드웨어 가속기(NPU)인 Ethos-U55를 탑재하고 있어, 일반 MCU에 비해 최대 수십 배 빠른 속도로 딥러닝 모델의 추론(Inference)을 처리할 수 있습니다.

* 이미지 획득: CMOS Sensor Interface (CCAP) 모듈을 통해 연결된 카메라가 실시간 영상 프레임을 수집하여 비어 있는 프레임 버퍼로 전달합니다.

* 전처리 (Pre-processing): CPU (Cortex-M55)가 캡처된 이미지의 크기를 모델 입력 규격(예: 96x96 RGB)으로 리사이징 및 정규화(Normalization)합니다.

* NPU 추론: 변환된 텐서(Tensor) 데이터를 Ethos-U55 NPU로 이송하여, 수 밀리초(ms) 만에 딥러닝 모델(CNN 기반 제스처 인식 모델)의 추론을 실행합니다.

* 출력 및 표시: 분류된 제스처 결과(Fist, Wave, Stop 등)에 따라 스마트 홈 제어 신호를 출력하고, External Bus Interface (EBI)로 구동되는 LCD 화면에 인식 결과 상자 및 라벨을 렌더링합니다.

---

▶ 2. 준비물 (BOM List) 및 하드웨어 구성

Nuvoton은 기계학습 학습 및 개발을 위해 올인원 개발 키트를 제공하고 있습니다.

* NuMaker-M55M1 개발보드: Cortex-M55 CPU 및 Ethos-U55 microNPU가 통합된 핵심 MCU 개발 키트.

* CMOS 카메라 모듈 (HM01B0 또는 OV2640): CCAP 인터페이스에 연결하여 실시간 영상 프레임을 캡처하는 용도.

* TFT-LCD 디스플레이 모듈: EBI 버스를 통해 연동되어 카메라 실시간 뷰 및 제스처 인식 결과를 시각적으로 표현하는 모듈.

---

▶ 3. 머신러닝 모델 개발 및 펌웨어 포팅

NuMicro M55M1의 Ethos-U55 NPU는 완전 정수형(Full INT8) 양자화 모델만 지원하므로, 학습부터 변환 단계까지 엄격한 데이터 가이드라인을 따라야 합니다.

▷ 1단계: CNN 모델 설계 및 학습 (PC/Colab Python 코드)

96x96 해상도의 컬러 손동작 이미지를 학습시키기 위한 가벼운 CNN 구조의 Keras 모델 학습 예제입니다.

`python

import tensorflow as tf

from tensorflow.keras import layers, models

1. 제스처 분류 모델 정의 (96x96 RGB 입력)

def create_gesture_model():

model = models.Sequential([

layers.Input(shape=(96, 96, 3)),

layers.Conv2D(16, (3, 3), activation='relu'),

layers.MaxPooling2D((2, 2)),

layers.Conv2D(32, (3, 3), activation='relu'),

layers.MaxPooling2D((2, 2)),

layers.Conv2D(64, (3, 3), activation='relu'),

layers.Flatten(),

layers.Dense(64, activation='relu'),

layers.Dropout(0.3),

layers.Dense(3, activation='softmax') # 3가지 클래스: Fist, Wave, Stop

])

return model

model = create_gesture_model()

model.compile(optimizer='adam',

loss='sparse_categorical_crossentropy',

metrics=['accuracy'])

`

▷ 2단계: Ethos-U55 NPU 구동을 위한 INT8 정수 양자화 (Quantization)

일반 float32 가중치를 갖는 딥러닝 모델은 NPU에서 돌릴 수 없습니다. 아래 파이썬 코드를 사용하여 모델의 가중치와 활성화 함수를 모두 INT8 범위로 양자화해 주어야 합니다.

`python

import numpy as np

1. 대표 데이터셋 제너레이터 정의 (양자화 기준 스케일링용)

def representative_data_gen():

# 학습 데이터 일부(약 100~200장)를 샘플링하여 부동소수점 매핑 범위를 설정합니다.

for input_value in tf.data.Dataset.from_tensor_slices(x_train).batch(1).take(100):

yield [tf.cast(input_value, tf.float32)]

2. TFLite 변환기 설정

converter = tf.lite.TFLiteConverter.from_keras_model(model)

converter.optimizations = [tf.lite.Optimize.DEFAULT]

converter.representative_dataset = representative_data_gen

3. NPU 제약 조건 적용 (Full Integer Only)

converter.target_spec.supported_ops = [tf.lite.OpsSet.TFLITE_BUILTINS_INT8]

converter.inference_input_type = tf.int8

converter.inference_output_type = tf.int8

4. 변환 및 저장

tflite_model_quant = converter.convert()

with open("gesture_model_quant.tflite", "wb") as f:

f.write(tflite_model_quant)

`

▷ 3단계: Vela Compiler를 활용한 하드웨어 명령어 최적화

양자화된 .tflite 모델이 완성되면, Arm Ethos-U 전용 컴파일러인 Vela를 실행하여 NPU 하드웨어 친화적 커맨드 스트림 파일로 최적화 빌드합니다.

`bash

vela 컴파일러를 통해 ethos-u55-128 아키텍처 환경에 맞춰 명령어 번들 생성

vela gesture_model_quant.tflite --accelerator-config ethos-u55-128 --output-dir ./output

`

Vela 컴파일러를 통해 생성된 gesture_model_quant_vela.tflite 바이너리 데이터 파일(C++ 포팅을 위해 바이트 배열 형태로 변환)을 Keil MDK 템플릿 프로젝트의 Model 디렉토리에 추가해 줍니다.

▶ 4. Nuvoton M55M1 공식 SDK 아키텍처 기반 펌웨어 구현

Nuvoton M55M1 공식 개발용 AppNote 가이드라인에 따른 펌웨어의 아키텍처는 보드 초기화(BoardInit), 메인 제어(main), 추론 작업(InferenceTask), 결과 후처리(PostProcessing) 등 4가지 모듈 구조로 표준 설계됩니다.

▷ 1단계: 메인 시스템 및 AI 리소스 초기화 (main.cpp)

시스템 클럭 설정 및 하드웨어 가속기(NPU), 센서(CCAP), LCD 디스플레이 등을 사용하기 위한 초기화 코드입니다.

`cpp

#include "BoardInit.hpp"

#include "YoloXnanoNu.hpp" // 누보톤 공식 ML 모델 래퍼 클래스

#include "FreeRTOS.h"

#include "task.h"

// 1. 이미지 센서(CCAP) 및 디스플레이 모듈 활성화 상수 정의

#define USE_CCAP 1

#define USE_DISPLAY 1

// 2. 누보톤 ML 어플리케이션 모델 인스턴스 선언 및 Tensor Arena 버퍼 할당

Arm::app::YoloXnanoNu model;

static uint8_t tensor_arena[1024 * 512]; // NPU 연산 임시 메모리

int main(void)

{

// BoardInit.cpp에 정의된 하드웨어 기본 리소스(CLK, UART) 초기화 호출

BoardInit();

// NPU 및 메모리 활성화를 포함한 모델 초기화 실행

if (!model.Init(tensor_arena, sizeof(tensor_arena))) {

printf("ML Model Initialization Failed!\n");

return -1;

}

// FreeRTOS 기반의 독립된 추론 처리 테스크 생성

xTaskCreate(InferenceTask, "InferenceTask", 4096, NULL, 3, NULL);

// RTOS 스케줄러 시작

vTaskStartScheduler();

while(1);

}

`

▷ 2단계: 카메라 프레임 수집 및 실시간 NPU 추론 루프 (InferenceTask.cpp)

카메라 센서의 원시 데이터 버퍼를 받아와 모델 형식으로 가공한 후, M55M1 NPU 하드웨어를 통해 즉시 추론을 돌리는 핵심 테스크 코드입니다.

`cpp

#include "FreeRTOS.h"

#include "task.h"

#include "YoloXnanoNu.hpp"

extern Arm::app::YoloXnanoNu model;

void InferenceTask(void *pvParameters)

{

while(1)

{

// 1. CCAP 카메라 버퍼 중 비어 있는(eFRAMEBUF_EMPTY) 버퍼 포인터 획득

uint8_t* frame_buf = get_empty_framebuf();

if (frame_buf != NULL)

{

// 2. 모델의 입력 텐서 버퍼 획득 (INT8 타입)

int8_t* input_tensor = model.GetInputTensor();

// 3. 카메라 프레임 이미지를 96x96 사이즈로 스케일링하고 정규화하여 복사

PreprocessImage(frame_buf, input_tensor);

// 4. M55M1 Ethos-U55 NPU 하드웨어 가속 추론 구동

if (model.Run() == true)

{

// 5. 추론 결과 데이터를 후처리 모듈로 전달

int8_t* output_tensor = model.GetOutputTensor();

DetectorPostProcessing(output_tensor);

}

// 사용 완료된 프레임 버퍼 해제

release_framebuf(frame_buf);

}

vTaskDelay(pdMS_TO_TICKS(10)); // 10ms 대기

}

}

`

▶ 5. 결론 및 응용 가능성

NuMicro M55M1 기반의 Edge AI 솔루션은 클라우드 서버와의 통신이 필요 없기 때문에 개인정보 침해(Privacy) 우려가 전혀 없으며, 지연 시간(Latency)이 거의 없는 실시간 밀리초 단위 반응이 가능합니다.

Cortex-M55 CPU와 Ethos-U55 microNPU의 결합은 경량 스마트 스위치 및 가전기기의 비접촉식 휴먼 머신 인터페이스(HMI) 구현을 위한 최적의 성능 대 전력비 효율성을 제공합니다.
